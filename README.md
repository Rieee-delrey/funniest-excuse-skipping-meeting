## What it does

`main.py` writes a single one-line excuse for skipping a pointless meeting, in the voice of someone who has heard "let's take this offline" one time too many, to `/output/entry.txt`. The file holds exactly that one line, with no trailing newline.

## How to run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
